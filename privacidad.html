Política de Privacidad

SHOPly | Aplicación académica

Última actualización: 25 de octubre de 2026

1. Introducción

SHOPly es una aplicación móvil desarrollada con fines académicos para demostrar el funcionamiento de una plataforma de comercio electrónico.

Esta Política de Privacidad describe qué información puede recopilarse durante el uso de SHOPly, para qué se utiliza y cómo pueden los usuarios solicitar su eliminación.

2. Información recopilada

Según las funciones utilizadas, SHOPly puede tratar los siguientes datos:

  • Nombre del usuario.
  • Dirección de correo electrónico.
  • Identificador de usuario.
  • Información básica del perfil.
  • Información de productos y pedidos simulados asociados a la cuenta.

3. Inicio de sesión

SHOPly permite autenticarse mediante correo electrónico y contraseña, Google y Facebook.

Cuando se utiliza Google o Facebook, la aplicación puede recibir información básica del perfil autorizada por el usuario y disponible a través del proveedor.

La autenticación se gestiona mediante Firebase Authentication. SHOPly no necesita conocer la contraseña personal de Google o Facebook del usuario.

4. Uso de la información

Los datos se utilizan para:

  • Identificar y autenticar a los usuarios.
  • Permitir el acceso a las funciones de SHOPly.
  • Administrar perfiles de comprador y vendedor.
  • Registrar y consultar pedidos simulados.
  • Mantener el funcionamiento de la aplicación.

5. Almacenamiento de datos

SHOPly utiliza servicios de Firebase, incluyendo Firebase Authentication y Cloud Firestore, para gestionar cuentas e información relacionada con las funcionalidades de la aplicación.

El tratamiento de datos por parte de estos servicios también está sujeto a las condiciones y políticas aplicables de sus proveedores.

6. Compras simuladas

SHOPly es un proyecto académico. Las compras realizadas dentro de la aplicación son simuladas y no representan transacciones comerciales reales.

7. Protección de la información

SHOPly utiliza mecanismos de autenticación y reglas de acceso a la base de datos para restringir las operaciones sobre información almacenada.

Ningún sistema informático puede garantizar una seguridad absoluta.

Esta política puede actualizarse cuando cambien las funcionalidades de SHOPly o las prácticas relacionadas con el tratamiento de información.
